# MCU Quay（芯埠）

## Canonical identity

- **English name:** MCU Quay
- **Chinese name:** 芯埠
- **Package identifier:** `mcu-quay`
- **License identifier:** `MQDL-1.0`
- **Tagline:** *A safe harbor between MCU devices and operators.*

“Quay” means a landing place beside the water. The name describes this
project's role as the controlled landing point between embedded devices,
network protocols, automation, and human operators. “芯埠” keeps the same idea
in Chinese: a dependable port for chips and devices.

## Usage

Use **MCU Quay（芯埠）** in documentation, screenshots, release notes, and
citations. Use `mcu-quay` for package and automation identifiers. The former
name “MCU Relay Backend” may be mentioned only when explaining migration or
repository history.
